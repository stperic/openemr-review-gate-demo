# OpenEMR D05 review-gate sandbox

This local demonstration starts at the pinned OpenEMR introduction revision `2ab074e827b9011d054df34723696feb9776e8e4`. It contains a narrow payment component and synthetic credentials. It is not an OpenEMR application deployment.

The trace graph is a retrospective draft created for the demo. Its owner has not accepted it. A candidate PR first retains the vulnerable portal, then applies a local corrected derivative. The trusted checker derives its render wrapper from the candidate portal file and runs PHP in an isolated Docker container. Snyk completion, route triage and authenticated AppSec approval remain separate obligations.
